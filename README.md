# PuzzleMood

Одиночные пазлы в браузере. Загрузите свою картинку или выберите встроенный пример, задайте сложность и соберите изображение.

| Уровень | Деталей |
| --- | ---: |
| Лёгкий | 12 |
| Средний | 48 |
| Сложный | 108 |
| Очень сложный | 192 |

Детали разложены вокруг рамки. Перетащите деталь на место или сначала выберите её, затем укажите ячейку. На клавиатуре Page Up и Page Down выбирают деталь, стрелки двигают курсор, а Enter ставит деталь. Кнопки масштаба приближают поле, а при увеличении его можно сдвигать за свободное место. Кнопка «Образец» показывает подсказку, «Только края» помогает начать с рамки, а «Звук» включает и выключает щелчок при сборке.

Текущий пазл и библиотека хранятся в IndexedDB в том же браузере. После сборки пазл автоматически попадает в библиотеку. Оттуда можно открыть изображение и скачать исходный файл. Поддерживаются JPG, PNG, WebP, AVIF и GIF до 20 МБ. Для пазла из GIF используется один кадр.

## Локальный запуск

Установите Python 3 и откройте [http://127.0.0.1:8000](http://127.0.0.1:8000) после запуска сервера.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Для запуска тестов нужен Node.js 20 или новее.

```sh
npm test
```

Для статического хостинга достаточно разместить `index.html`, `style.css`, `assets/` и `src/` в одной папке. Лицензии шрифтов Pangolin и Nunito Sans находятся в `assets/fonts/`.
